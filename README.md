# BoxTime

BoxTime is a free boxing round timer for Android: fight presets, a ring bell and ten-second clapper, spoken cues and combo callouts, four timer faces and a Wear OS watch app. It keeps going with the screen off. No adverts, no account.

Website: https://customgpter.github.io/boxtime/

Download: https://github.com/CustomGPTer/boxtime/releases/latest/download/BoxTime.apk
