# BoxTime

BoxTime is a free boxing round timer for Android. Set the round, the rest and the number of rounds, press Start, and it rings the bell, warns you before the end of the round and counts you back in, with the screen on or off. It can speak the round number and call punch combinations. It has no adverts, no accounts and no paid version.
